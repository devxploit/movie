# Análisis de Costos: Despliegue de Aplicación Spring Boot

## Contexto

Aplicación Spring Boot con:

- API backend (Java 21, Spring Boot 3.5.4)
- PostgreSQL (base de datos)
- Redis (caché de sesiones)
- Dashboard web administrativo (React/Vue/Angular)
- Tráfico: >100K requests/día (producción alta)
- Backups: básicos, ambiente dev/staging

## 1. Google Cloud - Kubernetes (GKE Autopilot)

### Componentes

- **Spring Boot API**: 1 pod (1 vCPU, 2GB RAM)
- **Dashboard Web**: 1 pod (0.5 vCPU, 1GB RAM)
- **PostgreSQL**: Cloud SQL db-g1-small (1 vCPU, 1.7GB RAM)
- **Redis**: 1 pod (0.5 vCPU, 1GB RAM)

### Costos Mensuales

| Componente | Especificaciones | Costo Mensual |

|------------|------------------|---------------|

| GKE Autopilot - API | 1 vCPU × $0.0445/h × 730h | $32.49 |

| GKE Autopilot - API Memory | 2GB × $0.0049225/h × 730h | $7.19 |

| GKE Autopilot - Dashboard | 0.5 vCPU × $0.0445/h × 730h | $16.24 |

| GKE Autopilot - Dashboard Memory | 1GB × $0.0049225/h × 730h | $3.59 |

| GKE Autopilot - Redis | 0.5 vCPU × $0.0445/h × 730h | $16.24 |

| GKE Autopilot - Redis Memory | 1GB × $0.0049225/h × 730h | $3.59 |

| Cloud SQL PostgreSQL (db-g1-small) | Instancia gestionada | $30.00 |

| Persistent Disk (50GB SSD) | Para PostgreSQL | $8.50 |

| Load Balancer | Ingress HTTP(S) | $18.00 |

| Network Egress | ~100GB/mes | $12.00 |

| **TOTAL MENSUAL** | | **~$147.84** |

**Nota**: Tarifa de gestión de clúster ($74.40/mes) cubierta por crédito gratuito de GKE.

### Ventajas

- Auto-escalado horizontal
- Gestión automatizada de infraestructura
- Alta disponibilidad built-in
- Monitoreo integrado con Cloud Operations
- Fácil implementación de CI/CD

### Desventajas

- Costo más elevado
- Curva de aprendizaje de Kubernetes
- Overhead operacional inicial

## 2. Google Cloud - VM Única (Containerizada)

### Especificaciones

- **Instancia**: e2-standard-2 (2 vCPUs, 8GB RAM)
- **Servicios**: Docker Compose con Spring Boot + PostgreSQL + Redis + Dashboard
- **Almacenamiento**: 100GB SSD persistent disk

### Costos Mensuales

| Componente | Costo Mensual |

|------------|---------------|

| e2-standard-2 (2 vCPU, 8GB RAM) | $61.76 |

| Persistent Disk SSD 100GB | $17.00 |

| Network Egress (~100GB) | $12.00 |

| Static IP | $7.20 |

| **TOTAL MENSUAL** | **~$98.00** |

## 5. Recomendación Final

### Para PRODUCCIÓN con tráfico alto (>100K req/día):

**OPCIÓN 1 (Óptima precio/rendimiento)**: **Hetzner Cloud CPX31** - $17.80/mes

**Justificación**:

- Excelente relación precio/rendimiento
- Hardware de alta calidad (NVMe, AMD EPYC)
- Tráfico ilimitado incluido (crítico para 100K+ requests/día)
- Ubicaciones en Europa y USA
- Backups automáticos incluidos
- Soporte decente y API robusta

**Configuración**:

```bash
# Stack completo containerizado
- Spring Boot API: 2GB RAM, 2 cores
- Dashboard Web: 1GB RAM, 1 core  
- PostgreSQL 16: 3.5GB RAM, 1 core
- Redis 7: 512MB RAM, 0.5 core
- Nginx reverse proxy: 512MB RAM, 0.5 core
- Monitoring (Prometheus + Grafana): 512MB RAM, 0.5 core
```

**OPCIÓN 2 (Si requieres Google Cloud)**: **Google Compute Engine e2-standard-2** - $98/mes

### Para DESARROLLO/STAGING:

**OPCIÓN RECOMENDADA**: **Oracle Cloud Always Free** - $0/mes

**Consideraciones**:

- Necesitarás compilar tu aplicación para ARM64
- Añadir a `build.gradle`:
```groovy
tasks.named('bootBuildImage') {
    builder = 'paketobuildpacks/builder-jammy-base'
    imageName = 'your-app'
    environment = [
        'BP_JVM_VERSION': '21',
        'BP_PLATFORM_API': '0.15'
    ]
}
```
